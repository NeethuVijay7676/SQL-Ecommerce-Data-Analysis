# SQL Project | E-commerce Data Analysis

SQL analysis of an e-commerce platform's customer orders, sales performance, product categories, sub-categories, state-wise and city-wise sales, and profitability using MySQL.

## 🛠️ Tools Used

* MySQL
* MySQL Workbench
* SQL

## 📊 Dataset Source

The original datasets were imported into MySQL. The project uses three related datasets:

List_of_order – contains order ID, order date, customer name, state, city

Order details -contains order ID, amount, profit, quantity, category, sub-category

Sales target- contains month of order date, category, target

**Dataset Source:** 
[E-commerce Dataset – https://www.kaggle.com/datasets/benroshan/ecommerce-data)

# 3. Find the total sales Amount generated by each State, sorted from highest to lowest revenue.
select l.State,sum(o.Amount) as total_amount 
from list_of_orders as l
inner join order_details as o
on l.order_id=o.order_id
group by l.State
order by total_amount desc; 

**Purpose:** Identifies State-wise Sales Performance

# 4. Find the total Profit for each State and Category combination, showing only the combinations that resulted in an overall net loss.
select l.State,o.Category, sum(o.Profit) as total
from list_of_orders as l
inner join order_details as o
on l.order_id=o.order_id
group by l.State,o.Category
having total<0;

**Purpose:** Identifies State and Category-wise Loss Analysis

#5.Rank each sub_category within its respective Category based on total Profit (from highest to lowest), displaying Category, sub_category, total_profit, and profit_rank.

select Category, sub_category, sum(profit) as total_profit, rank() over(partition by category order by sum(profit) desc) as profit_rank 
from order_details
group by Category, sub_category;
